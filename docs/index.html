About

HARD.CORE.WEB is a reusable React-based frontend base for web projects that connect to the HARD.CORE API. It is not a full ERP, but a starting point for custom admin panels, dashboards, or management UIs, providing authentication, responsive admin UI, CRUD-ready modules, and a modern build flow.

Features

  • JWT authentication and session handling
  • Responsive admin UI (desktop/mobile)
  • CRUD-ready modules: Empresas, Menús, Clientes, Perfiles, Usuarios, Mensajes (with real-time messaging via SignalR client)
  • Shared Axios service pattern for REST API
  • Token persistence and automatic header injection
  • Envelope-based API response handling
  • Modern Vite-based build and deploy flow
  • Mobile client available (Expo/React Native)

Tech Stack

Frontend

React 19, Vite 8, TailwindCSS 4, Axios

Mobile

Expo (React Native), React Navigation, AsyncStorage

Tooling

Node.js 20+, npm 10+, ESLint 9

Usage

Web App

  • Install: git clone https://github.com/mrodriguex/hard.core.web.git
  • Setup: cd hard.core.web/hardcore-web && npm install
  • Run: npm run dev (default: http://localhost:5173)
  • Build: npm run build (output: dist/)
  • Preview: npm run preview
  • Available modules: Empresas, Menús, Clientes, Perfiles, Usuarios, Mensajes

Mobile App

  • Install: cd hardcore-mobile && npm install
  • Run: npm run start (open with Expo Go or emulator)

Configuration

  • API base URL: https://localhost:7026 (move to VITE_API_URL for multi-env)
  • Token key: token (browser storage)
  • Authorization header: Authorization: Bearer {'{token}'}

API Overview

Key endpoints:

  • Login: POST /api/v1/Auth/login
  • Get All Entities: GET /api/v1/<Entity>/GetAll
  • Get By Id: GET /api/v1/<Entity>/GetById
  • Add: POST /api/v1/<Entity>/Add
  • Update: PUT /api/v1/<Entity>/Update
  • Delete: DELETE /api/v1/<Entity>/Delete

Entities: Empresa, Menu, Cliente, Perfil, Usuario, Mensajes

See README for request/response examples.
